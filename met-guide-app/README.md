# Met Guide App

Standalone Next.js app for the Met + Cloisters family museum guide.

## Vercel import

1. In Vercel, choose **Add New → Project**.
2. Import `moonsup-ai/practice-project`.
3. Set **Production Branch** to `met-guide-next`.
4. Set **Root Directory** to `met-guide-app`.
5. Framework preset: **Next.js**.
6. Deploy.
7. In **Settings → Deployment Protection**, make sure Production is publicly accessible.

No environment variables are required.
